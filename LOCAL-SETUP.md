# Local setup & GitHub push

## Run locally
```bash
npm install        # or: bun install
npm run dev        # http://localhost:8080
npm run build      # production build
```

## Push to GitHub
```bash
git init
git add .
git commit -m "Initial commit: portfolio"
git branch -M main
git remote add origin https://github.com/ANASF1412/<repo-name>.git
git push -u origin main
```

## Images
Every image is a plain file in `public/images/` — no external CDN, nothing to
configure. Folders: `projects/`, `certifications/`, `achievements/`,
`internships/`, `profile/`. Each original ships with 480/768/1200/1600px `.webp`
variants generated by `scripts/gen-image-variants.py`.

Add a new image: drop the .jpg/.png into the right folder, run
`python3 scripts/gen-image-variants.py`, then reference `/images/<folder>/<name>.<ext>`
in `src/lib/portfolio-data.ts`. `scripts/audit-portfolio-assets.ts` fails the
build if a card points at a file that doesn't exist.
